# Free

## Chat

[Open Chat](https://toluwerr.github.io/Free/)

A browser version of the Roblox chat client. Connect to the same chat server, with channels, replies, mentions, code blocks, and link sharing.

[View chat source](./index.html)

## Roblox Username Lookup

[Open Username Lookup](https://toluwerr.github.io/Free/username-lookup.html)

Search for a Roblox username, view its user ID, and copy the number.

[View lookup source](./username-lookup.html)
